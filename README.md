# Vilks un olas – LCD spēle

Retro LCD stila spēle pārlūkā (viens HTML fails, bez atkarībām), iedvesmota no 80. gadu kabatas elektroniskajām spēlēm.

Četras vistas dēj olas, kas ripo pa teknēm. Palīdzi vilkam – pārvieto viņa grozu uz pareizo stūri un noķer tās. Trīs sasistas olas – spēle beigusies. Jo vairāk punktu, jo ātrāk un vairāk olu.

## Vadība
- Bultiņas vai `Q` `A` / `P` `L` – groza pozīcija
- Atstarpe / Enter – sākt
- Telefonā: pieskaries ekrāna stūrim vai izmanto pogas zem ekrāna

## Palaišana
Atver `index.html` pārlūkā vai uzliec GitHub Pages (Settings → Pages → branch `main`, root).

Spēles tēls un grafika ir oriģināli.
